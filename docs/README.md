# О geometric_lib
* Язык Python
* Содержит функции для подсчёта площади и периметра геометрических фигур:
  * Треугольник
  * Квадрат
  * Круг
  * Прямоугольник
# Функции 
* **triangle.area(a,h)**
  * Возвращает площадь треугольника
  * Параметры
    * a (float): основание треугольника
    * h (float): высота треугольника
  * Возвращаемое значение
    * a\*h/2 (float): площадь трегольника с основанием a и высотой h
  * Пример вызова:
    *  ```print(triangle.area(2.3,8.0))``` выведет площадь треугольника с основанием 2.3 и высотой 8
* **triangle.perimeter(a,b,c)**
  * Возвращает периметр треугольника
  * Параметры
    * a,b,c (float): стороны треугольника
  * Возвращаемое значение
    * a+b+c (float): периметр треугольника со сторонами a, b и c
  * Пример вызова:
    *  ```print(triangle.perimeter(2.0,3.0,8.0))``` выведет периметр треугольника со сторонами 2, 3 и 8
* **circle.area(r)**
  * Возвращает площадь окружности
  * Параметры
    * r (float): радиус окружности
  * Возвращаемое значение
    * Pi\*r<sup>2</sup> (float): площадь окружности с радиусом r
  * Пример вызова:
    *  ```print(circle.area(3.0))``` выведет площадь окружности с радиусом 3
* **circle.perimeter(r)**
  * Возвращает длину окружности
  * Параметры
    * r (float): радиус окружности
  * Возвращаемое значение
    * Pi\*r\*2 (float): длина окружности с радиусом r
  * Пример вызова:
    *  ```print(circle.perimeter(3.0))``` выведет длину окружности с радиусом 3
* **square.area(a)**
  * Возвращает площадь квадрата
  * Параметры
    * a (float): длина стороны квадрата
  * Возвращаемое значение
    * a\*a (float): площадь квадрата со стороной a
  * Пример вызова:
    *  ```print(square.area(3.0))``` выведет площадь квадрата со стороной a
* **square.perimeter(a)**
  * Возвращает периметр квадрата
  * Параметры
    * a (float): длина стороны квадрата
  * Возвращаемое значение
    * a\*4 (float): периметр квадрата со стороной a
  * Пример вызова:
    *  ```print(square.perimeter(3.0))``` выведет периметр квадрата со стороной a
* **rectangle.area(a,b)**
  * Возвращает плошадь прямоугольника
  * Параметры
    * a (float): длина стороны прямоугольника
    * a (float): длина другой стороны прямоугольника
  * Возвращаемое значение
    * a\*b (float): площадь прямоугольника с сторонами a и b
  * Пример вызова:
    *  ```print(rectangle.area(3.0,2.0))``` выведет площадь прямоугольника со сторонами 2 и 3
* **rectangle.perimeter(a,b)**
  * Возвращает периметр прямоугольника
  * Параметры
    * a (float): длина стороны прямоугольника
    * a (float): длина другой стороны прямоугольника
  * Возвращаемое значение
    * 2\*(a+b) (float): периметр прямоугольника с сторонами a и b
  * Пример вызова:
    *  ```print(rectangle.perimeter(3.0,2.0))``` выведет периметр прямоугольника со сторонами 2 и 3
